# ikao 刷题平台 · 安装指导书

> 面向同学 / 同事（非开发人员）。按本文操作即可，**无需安装 Python、Node.js 等任何环境**。

---

## 一、运行环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| 浏览器 | Edge / Chrome 均可（系统自带也可） |
| 磁盘空间 | 约 300 MB（含题库与运行文件） |
| 网络 | **完全离线可用，无需联网** |
| 其他 | 无需管理员权限 |

---

## 二、你会拿到什么

一个压缩包，例如 `ikao-1.0.zip`，解压后目录如下：

```
ikao-1.0/
├── ikao.exe              ← 主程序，双击它启动
├── start-ikao.bat        ← 备用启动方式（效果相同）
├── 安装指导书.md         ← 本文档
├── VERSION.txt           ← 版本标记
├── data/                 ← 数据目录（题库与你的作答记录都存这里）
└── _internal/            ← 运行环境与程序资源（请勿删除）
```

---

## 三、安装步骤（3 步，约 1 分钟）

### 第 1 步：解压

把 `ikao-1.0.zip` 解压到任意位置，**建议**放到一个固定且路径简单的目录，例如：

```
D:\ikao-1.0
```

> 注意：**不要**只把 `ikao.exe` 单独拖出来运行，必须保留同目录下的 `_internal/` 文件夹。
> 建议不要放在 `C:\Program Files` 下（可能因权限导致数据写入失败）。

### 第 2 步：启动

进入解压后的目录，双击 **`ikao.exe`**（或 `start-ikao.bat`）。

会弹出一个黑色命令行窗口，显示类似内容：

```
==============================================================
  ikao 刷题平台  正在启动，请稍候 ...
==============================================================
[题库] 首次启动，正在导入内置题库 seed_questions.json，请稍候 ...
[题库] 完成：解析 6，入库 5，重复 1，失败 0。
--------------------------------------------------------------
  访问地址：http://127.0.0.1:8010/
  浏览器将自动打开；本窗口是服务进程，关闭窗口即退出程序。
--------------------------------------------------------------
```

- **首次启动**会自动导入内置题库，稍等几秒；
- 之后启动会显示「当前已有 N 道题，跳过内置题库导入」，秒开。

### 第 3 步：开始使用

浏览器会自动打开 `http://127.0.0.1:8010/`。若没有自动打开，手动在浏览器地址栏输入：

```
http://127.0.0.1:8010/
```

> ⚠️ 使用期间**不要关闭那个黑色命令行窗口**，它是程序本体；关闭窗口 = 退出程序。

## 四、界面速览

| 位置 | 功能 |
|---|---|
| 顶栏 | 开始刷题 / 错题本 / 收藏夹 / 统计看板 / 题库 / 档案切换 |
| 首页 | 欢迎区 + 学习概览 + 功能入口 |
| 刷题页 | 5 种模式：顺序练题、背题模式、随机练习、错题重做、我的收藏（切换即刷新题目） |
| 背题模式 | 直接显示答案与解析，只读高亮，不计入统计流水 |
| 错题本 | 自动收录答错的题，可「移出错题本」 |
| 统计看板 | 正确率、题型/模式分布、练习趋势、高频错题 |
| 题库 | 题目检索、新增/编辑/删除、导入（JSON / CSV / Excel，可下载 Excel 模板）、导出 CSV、导入日志 |

## 五、数据与备份

- 所有数据都在 **`data\ikao.db`** 这一个文件里（SQLite 数据库）。
- **备份**：直接复制整个 `data` 文件夹即可。
- **迁移到另一台电脑**：把 `data` 文件夹一起拷过去覆盖，进度与作答记录即完整保留。
- **升级程序**：用新版本的 `ikao.exe` 及 `web/`、`_internal/` 覆盖，**保留原来的 `data/` 文件夹** 即可。

## 六、常见问题

**1. 提示「Windows 已保护你的电脑」/ SmartScreen 拦截**

因为程序未做数字签名。点击「更多信息」→「仍要运行」；或在杀毒软件里把该目录加入信任/白名单。

**2. 浏览器没有自动打开**

手动访问 `http://127.0.0.1:8010/` 即可。

**3. 提示端口被占用 / 无法访问**

程序会自动从 8010 往后找可用端口（8011~8019），请**以黑窗口里打印的「访问地址」为准**。
若想固定端口，可先设置环境变量再启动：

```powershell
$env:IKAO_PORT = "8020"
.\ikao.exe
```

**4. 双击 exe 后窗口一闪而过**

说明启动报错。请用命令行方式运行以查看原因：

```
Win + R → 输入 cmd → 回车
cd /d D:\ikao-1.0
ikao.exe
```

**5. 页面能打开但显示数据为空**

首次启动的题库导入可能还在进行，稍等后按 F5 刷新；或查看黑窗口是否有报错信息。

**6. 想清空所有作答记录（保留题目）**

在页面里删除/新建「档案」即可（顶栏可切换档案，作答数据按档案隔离）。

**7. 想彻底重置（连题目一起清空）**

关闭程序，删除 `data\ikao.db`，重新启动 `ikao.exe`，会自动重新导入内置题库。

**8. 卸载**

关闭程序，直接删除整个 `ikao-1.0` 文件夹即可，不留任何注册表项。

## 七、进阶（可选）

- **同一局域网内多台电脑访问**：默认只监听本机 `127.0.0.1`，出于安全考虑未开放局域网访问。如确需开放，属于高级用法，请让打包同学调整监听地址后重新打包。
- **导入自己的题库**：进入「题库 → 导入」，支持 JSON / CSV / Excel（`.xlsx`）文件；可先点「下载 Excel 模板」，按表头填好后再上传。导入时自动按题干相似度去重（默认阈值 0.9）。字段格式见 `docs/题库格式说明.md`。
- **导出题库**：在「题库管理」页点「导出 CSV」，会按当前筛选条件导出为 CSV 文件（列格式与导入模板一致，改完可直接再导入）。

## 八、联系与反馈

使用中遇到问题，请把**黑窗口的报错文字**和**浏览器 F12 控制台的红色报错**一并反馈给打包同学，便于快速定位。
