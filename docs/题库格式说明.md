# 题库格式说明（JSON / CSV / Excel）

本系统支持三种题库文件：**JSON**、**CSV**、**Excel（.xlsx）**。导入接口是**宽进**的：字段名、题型名、选项结构、答案写法都尽量容错；
但导入后统一**严出**为固定结构，后续刷题、统计都基于这套固定结构。

> 建议流程：在导入页点「下载 Excel 模板」→ 按表头填好 → 上传导入。导出 CSV 与本模板列格式完全一致，改完可原样回导。

---

## 1. 顶层结构（仅 JSON）

三种都支持，推荐第 1 种：

```json
{ "meta": { "name": "ikao 题库", "version": "1.0" }, "questions": [ ... ] }
```

```json
[ { "title": "..." }, { "title": "..." } ]
```

```json
{ "data": [ ... ] }     // 也支持 list / items / records / questionList
```

`meta` 为可选字段，仅作说明用，不参与入库。

---

## 2. 单题结构

```json
{
  "id": "s-001",
  "type": "single",
  "title": "题干，支持 $LaTeX$ 公式",
  "options": ["A. 选项一", "B. 选项二"],
  "answer": "A",
  "analysis": "解析，支持 $LaTeX$"
}
```

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `title` | **必填** | 题干。为空会记入失败明细 |
| `type` | 可选 | 题型，缺失时按选项与答案自动推断 |
| `options` | 可选 | 选择题选项；判断题、简答题可省略 |
| `answer` | 可选 | 答案，写法见第 4 节 |
| `analysis` | 可选 | 解析 |
| `id` | 可选 | 原题库中的编号，仅作参考保留 |

> 其他未列出的字段会被自动忽略，不影响导入。

### 字段名容错

| 规范字段 | 兼容写法 |
| --- | --- |
| `title` | `stem` / `question` / `content` / `name` / `题干` / `题目` / `问题` |
| `type` | `kind` / `qtype` / `题型` / `类型` |
| `options` | `choices` / `option` / `选项` |
| `answer` | `answers` / `correct` / `correct_answer` / `right_answer` / `答案` / `正确答案` / `参考答案` |
| `analysis` | `explanation` / `analyze` / `explain` / `解析` / `分析` / `说明` |
| `id` | `qid` / `code` / `编号` / `题号` |

---

## 3. 题型（`type`）

统一取值只有四种：

| 取值 | 含义 |
| --- | --- |
| `single` | 单选题 |
| `multiple` | 多选题 |
| `judge` | 判断题 |
| `short` | 简答题 |

兼容的中文 / 英文写法：

- 单选：`单选` `单选题` `单项选择题` `single` `radio` `singlechoice`
- 多选：`多选` `多选题` `多项选择题` `multiple` `multi` `checkbox`
- 判断：`判断` `判断题` `对错题` `judge` `truefalse` `boolean` `tf`
- 简答：`简答` `简答题` `问答` `填空题` `short` `essay` `subjective` `text`

**自动推断规则**（未提供 `type` 时）：

1. 有选项且答案含多个选项字母 → `multiple`
2. 有选项 → `single`
3. 无选项且答案是「对/错/正确/错误/true/false/√/×」→ `judge`
4. 其余 → `short`

---

## 4. 选项（`options`）与答案（`answer`）的写法

### 选项

三种写法都支持，导入后统一为 `[{"key": "A", "text": "..."}]`：

```json
"options": { "A": "选项一", "B": "选项二" }
```

```json
"options": ["A. 选项一", "B. 选项二"]      // 自动剥离 A. / A、/ (A) 前缀
```

```json
"options": [ { "key": "A", "text": "选项一" } ]
```

若列表项没有字母前缀，则按顺序自动编号 A、B、C……

### 答案

导入后统一为：

| 题型 | 统一结构 | 可接受的原始写法 |
| --- | --- | --- |
| `single` | `"A"` | `"A"` / `"A."` / `"(A)"` / `"答案：A"` |
| `multiple` | `["A","C"]`（去重 + 排序） | `["A","C"]` / `"AC"` / `"A、C"` / `"A,B"` |
| `judge` | `true` / `false` | `true`/`false` / `"对"`/`"错"` / `"正确"`/`"错误"` / `"√"`/`"×"` / `1`/`0` |
| `short` | `"参考答案文本"` | 任意文本 |

---

## 5. 公式（LaTeX）

- 行内公式：`$...$`
- 行间公式：`$$...$$`（也兼容 `\(...\)`、`\[...\]`）
- 题干、选项、答案、解析全部支持
- 导入时**不会改动原文**，公式原样保存；前端用 KaTeX 渲染
- JSON 中反斜杠需转义，例如 `\frac` 要写成 `"\\frac"`

---

## 6. 去重规则

导入时对每题执行两级判重：

1. **精确命中**：归一化后题干的 md5 相同 → 直接判定重复
2. **模糊命中**：相似度 ≥ 阈值（默认 `0.90`，导入页可调）→ 判定重复

归一化会做：去 HTML 标签、全角转半角、去标点与空白、转小写、剥离 `\frac` 等 LaTeX 命令名与 `$`。
因此「`x^{2}`」与「`x^2`」、以及仅标点/空格不同的同一道题都会被识别为重复。

重复题目会**跳过不入库**，并在导入日志明细中记录：`命中的已有题目 id` + `相似度`。

---

## 7. 导入结果说明

每次导入都会生成一条日志，包含三个数字与逐条明细：

| 状态 | 含义 |
| --- | --- |
| 已入库（success） | 成功写入题库，明细中给出新题目 id |
| 重复（duplicate） | 与已有题目重复，跳过；明细给出命中 id 与相似度 |
| 失败（failed） | 缺题干等格式问题；明细给出失败原因 |

批次整体状态：`success`（无失败）/ `partial`（部分成功）/ `failed`（全部失败）。

## 9. CSV / Excel 表格格式

CSV（`.csv` / `.txt`）与 Excel（`.xlsx` / `.xlsm`）使用**同一套列定义**，首行为表头。
在导入页点「下载 Excel 模板」即可得到带示例行与说明页的 `.xlsx` 模板。

### 列定义（顺序固定）

| 列名 | 是否必填 | 说明 |
| --- | --- | --- |
| `编号` | 可选 | 原题号，仅作参考 |
| `题型` | 可选 | 单选题 / 多选题 / 判断题 / 简答题（缺失时按选项与答案自动推断） |
| `题干` | **必填** | 题目正文，支持 LaTeX 公式 |
| `选项A` ~ `选项H` | 可选 | 选择题逐列填写；判断题、简答题留空 |
| `答案` | 可选 | 写法见第 4 节（判断题填 `正确` / `错误`） |
| `解析` | 可选 | 答案解析，支持 LaTeX 公式 |

示例（单选题）：

| 编号 | 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 单选题 | TCP 工作在哪一层？ | 传输层 | 网络层 | 应用层 | 链路层 | A | TCP 属于传输层协议。 |

### 表格格式的容错能力

- **表头别名**：中英文均可（如 `题干`/`title`、`答案`/`answer`、`解析`/`analysis`、`选项A`/`optionA`）。
- **表头定位**：表头上方允许有若干空行或说明行，会自动向下查找表头行。
- **单一「选项」列**：也可以只写一列「选项」，把多个选项塞在同一个单元格里，用换行、`|` 或 `;` 分隔，形如 `A. 选项一`、`A、选项二`、`A) 选项三`，会自动拆分。
- **编码**：CSV 依次尝试 `utf-8-sig` / `utf-8` / `gb18030` / `utf-16`，基本不会出现中文乱码。

### 注意

- **不支持旧版 `.xls`**：请用 Excel 另存为 `.xlsx` 后再导入。
- **导出 CSV**：题库管理页的「导出 CSV」按上述列定义输出，并带 UTF-8 BOM，方便 Excel 直接双击打开；导出文件可直接修改后再导入。
- 单文件上限 **32 MB**。
