# 打包说明（ikao v1.0 免安装绿色版）

本文说明如何把本项目打包成「队友无需安装 Python / Node 也能直接双击运行」的 Windows 绿色版。

---

## 1. 产物形态

| 项目 | 说明 |
|---|---|
| 打包方式 | PyInstaller `onedir`（目录版，启动快、比 onefile 稳定） |
| 入口 | `ikao.exe`（同时附带 `start-ikao.bat`） |
| 运行方式 | 双击 → 启动本地服务（默认 `http://127.0.0.1:8010`）→ 自动打开浏览器 |
| 依赖 | 后端 API + 前端 `web/dist` + 内置示例题库 JSON，全部打进包内 |
| 首次启动 | 检测到题库为空时，自动导入内置示例题库，写入 `data/ikao.db` |
| 数据存放 | `ikao.exe` 同级的 `data/` 目录（升级时保留该目录即可） |

---

## 2. 前置环境（仅打包机需要）

- Python 3.10+（与开发环境一致）
- Node.js 18+（构建前端）
- Windows 10/11 x64

---

## 3. 一键打包

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_portable.ps1
```

脚本依次完成 4 步：

1. `web/` 目录 `npm install`（首次）+ `npm run build` → 生成 `web/dist`
2. `pip install -r server/requirements.txt pyinstaller`
3. `python -m PyInstaller packaging/ikao.spec --noconfirm --clean` → `dist/ikao/`
4. 组装发布目录 `release/ikao-1.0/`

完成后把 `release\ikao-1.0` 整个文件夹压缩发给队友即可。

---

## 4. 手动分步（等价于脚本）

```powershell
cd web; npm install; npm run build; cd ..
python -m pip install -r server/requirements.txt pyinstaller
python -m PyInstaller packaging/ikao.spec --noconfirm --clean
```

## 5. 产物结构

```
release/ikao-1.0/
├── ikao.exe                 # 主程序（双击启动）
├── start-ikao.bat           # 备用启动脚本
├── VERSION.txt
├── 安装指导书.md            # 给队友的安装手册（docs/ 下的 md 会全部一起带上）
├── 打包说明.md
├── 题库格式说明.md
├── data/
│   └── seed_questions.json
└── _internal/               # Python 运行时、三方库、web/dist 等运行资源（PyInstaller 生成，勿删）
```

> 首次运行后会自动新增 `data/ikao.db`（题库与作答数据）。
>
> 说明：PyInstaller 6.x 的 onedir 产物会把 `web/dist` 等资源放在 `_internal/` 下，
> 运行时 `sys._MEIPASS` 即指向该目录，`config.py` 的 `RESOURCE_ROOT` 能正确定位到 `web/dist`。

---

## 6. 三个关键文件

### `packaging/launcher.py`（启动器 / 打包入口）

- 自动挑选可用端口：默认 8010，被占用则依次尝试 8011~8019；
- 题库为空时自动导入内置题库（优先读 exe 同级 `data/seed_questions.json`，其次读包内资源）；
- 启动服务并自动打开浏览器。

### `packaging/ikao.spec`（PyInstaller 配置）

- `datas`：把 `web/dist` 打到 `web/dist`、把 `data/seed_questions.json` 打到 `data/`；
- `hiddenimports`：补齐 uvicorn 动态加载的子模块（`h11_impl`、`loops.asyncio`、`lifespan.on`）；
- `excludes`：排除 `httptools / uvloop / websockets / wsproto / watchfiles` 等编译件（启动器强制使用纯 Python 的 `h11 + asyncio`，无需它们，可显著减小体积、降低打包踩坑概率）。

### `config.py` 的路径适配

`RESOURCE_ROOT` / `DATA_ROOT` 已适配冻结态：只读资源取 `sys._MEIPASS`，可写数据取 exe 所在目录。**因此不要把 `data/` 放进 `_internal/`，否则升级或清理会被清空。**

## 7. 改名称 / 版本号 / 图标

| 想改什么 | 改哪里 |
|---|---|
| 应用名（顶栏与首页显示） | `server/app/config.py` 的 `app_name`（当前为 `ikao`） |
| 版本号 | `server/app/config.py` 的 `version`（当前为 `1.0`）；同时改 `scripts/build_portable.ps1` 里的 `$Version` |
| 浏览器标签页标题 | `web/src/router/index.js` 的 `document.title` |
| 图标 | 把 `ico` 文件放到 `packaging/`，然后修改 `packaging/ikao.spec` 中 `EXE(..., icon="packaging/ikao.ico")` |

## 8. 打包后自测清单

```powershell
# 1) 全流程接口测试（用临时库，不动正式数据）
python scripts\full_flow_test.py

# 2) 直接运行打包产物
release\ikao-1.0\ikao.exe
```

手工核对：

- [ ] 浏览器自动打开 `http://127.0.0.1:8010/`，顶栏显示 `ikao v1.0`
- [ ] 首页「题库总题数」为内置示例题库题数（首次启动自动导入完成）
- [ ] 顺序练题 / 背题模式 / 随机练习 / 错题重做 / 我的收藏，切换后立即刷新题目
- [ ] 背题模式直接看到答案与解析，且不计入统计
- [ ] 错题本、收藏夹、统计看板数据正确
- [ ] 关闭控制台窗口后服务停止，再次双击可正常恢复（数据仍在）

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| `未找到 web/dist` | 先执行 `cd web; npm run build` 再打包 |
| 打包体积过大 | 确认 `excludes` 未被删改；不要安装 `numpy/pandas` 到打包环境 |
| 双击 exe 闪退 | 用 `cmd` 方式运行 exe 以查看报错：`cd release\ikao-1.0 & ikao.exe` |
| 队友无法导入题库 | 检查 `data/seed_questions.json` 是否随包存在；否则需手动通过界面导入 |
| 杀软误报 | 未签名 exe 常见，添加信任或将目录加入白名单 |
| 生成的文件名乱码（如 `鍚姩 ikao.bat`） | 说明脚本被 PowerShell 5.1 按 GBK 解码了 UTF-8 源码。`build_portable.ps1` 已改为**纯 ASCII 脚本**，产出的文件名也全部为 ASCII（`start-ikao.bat`），请保持该约定，**不要再往脚本里粘贴非 ASCII 字符**（含注释） |
| 改了后端接口/前端代码后功能异常 | 必须重新 `npm run build` 后再打包，否则包内是旧前端 |

---

## 10. 与「开发模式」的关系

- 开发调试仍用 `scripts\dev.bat`（后端 8010 + 前端 5173 热更新）；
- 打包只影响 `release/` 产物，不改变开发流程。
